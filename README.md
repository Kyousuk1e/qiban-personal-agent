# 栖伴 · Personal Agent

一个面向个人的本地助手原型：聊天、可编辑记忆、后台任务、一次性提醒、受限文件工具。以 Muse 等 personal agent 的使用方向为灵感，独立实现，无官方关联。

## 快速开始

需要 **Node.js 24+**（使用内置 SQLite），不需要 Python 或额外数据库。

```sh
npm ci
npm run dev
```

打开 **http://127.0.0.1:5173**。开发启动器同时运行网页、API 和独立 Worker。首次运行会自动创建 `data/` 与 `workspace/`。

### 无密钥体验

默认是明确标注的演示模式，不调用 AI，以下操作真实写入本地：

- `/files`：列出工作文件。
- `/note 内容`：创建 Markdown 笔记。
- `/remember 偏好`：生成待确认记忆，打开任务详情后保存。
- 在记忆页添加、修改、删除个人偏好。
- 在任务页安排一次性提醒；到期后显示站内通知。

演示模式不会假装理解任意自然语言。

### 连接模型

1. 复制 `.env.example` 为 `.env`。
2. 填写服务商的 `MODEL_API_KEY`、`MODEL_BASE_URL` 和 `MODEL_NAME`。
3. 重启服务。也可在网页设置中修改地址与模型名（网页设置优先于环境变量）。
4. 发送“列出我的文件”验证连接。模型需支持 Chat Completions API 的 function/tool calling 格式；各服务商参数兼容性可能不同。

基础地址例如 `https://你的服务商域名/v1`，系统会追加 `/chat/completions`。密钥仅从后端环境变量读取，不返回前端、不存 SQLite。支持本机 HTTP 模型接口，远程接口必须 HTTPS。清空网页里的地址和模型名回到演示模式。

**配置模型意味着相关对话、最近 30 条记忆和工具读出的文件片段会发送到该模型服务商；本地存储不等于模型推理也在本地。** 使用无密钥的本地模型服务时，可以不填写密钥。

## 生产构建（仍为本机单用户）

```sh
npm run build
npm start
```

打开 **http://127.0.0.1:4317**。`npm start`同时启动 API 和 Worker；如需分别管理进程，可用`npm run api`和`npm run worker`，不要与 `npm start`重复运行。默认只监听回环地址，不要直接暴露公网。开发模式使用固定 API 端口 4317；自定义`PORT` 时应同步修改 Vite 代理。

## 已实现

| 能力     | 实现范围                                                               |
| -------- | ---------------------------------------------------------------------- |
| 聊天     | 持久化多会话；异步任务，轮询进度，最终回复（未实现 token 流式输出）    |
| 模型工具 | 列文件、读文件、新建文件、提出记忆建议、创建提醒                       |
| 记忆     | 用户确认后保存，可编辑、删除；最多 100 条，模型加载最近 30 条          |
| 后台任务 | 独立 Worker、SQLite 原子领取、取消、120 秒超时、最多 8 轮模型调用      |
| 提醒     | 一次性任务、站内未读通知、离线后补发；输入使用浏览器时区，展示北京时间 |
| 文件     | 单层专用目录，txt/md/csv/json，200 KB 上限；拒绝路径穿越、链接及覆盖   |
| 审计     | 每个任务的工具、状态、错误和模型返回用量记录                           |

## 可靠性与边界

- 关闭网页后后台任务仍执行；电脑关机/休眠时不能执行。服务恢复后，到期提醒会补发。
- 本版本只启动一个 Worker。异常退出后等待 15 秒使心跳过期，再重启。
- 服务启动时，将中断的执行中任务标记失败，不自动重放，避免重复副作用；部分文件或提醒可能已创建，需先查看记录。
- 取消阻止后续步骤并中断模型请求，不撤销已创建的文件或提醒。新建的提醒作为独立任务管理。
- 工具无 Shell、邮件、支付、删除文件及任意路径访问权限；模型生成的记忆建议需要手动确认。
- 文件和网页内容均应视为不可信输入。系统提示只是辅助防护，实际路径、大小和工具白名单由程序校验。
- 本机程序及工作目录应属于可信用户；这不是针对同机恶意进程的安全沙箱。未实现登录、多用户隔离或 VM 隔离。
- 不能联网搜索、操作浏览器、操作整个电脑、收发邮件，也不支持重复提醒。本原型不等同于完整 Muse 产品。
- 不自动重试有副作用的模型任务，不会宣称提供 exactly-once 外部执行保证。

## 数据与备份

- `data/agent.sqlite`：会话、记忆、任务、设置、审计。
- `workspace/`：工作资料与生成结果。
- `.env`：本机模型凭据。

以上路径均已被 Git 忽略。发布代码前请运行 `git status` 检查，不要强制添加。备份时先停止 API 和 Worker，再复制整个 `data/` 和 `workspace/`；单独备份 SQLite 主文件可能遗漏 WAL 中的数据。`.env` 按凭据文件保管。

## 验证

```sh
npm run check
```

测试涵盖 API 来源保护、文件边界、记忆生命周期、后台聊天、定时任务去重、取消、中断恢复，以及 mock 模型的真实工具循环。不消耗模型额度。Windows 未启用开发者模式时，符号链接创建测试会明确跳过。

## 目录

```text
src/              React + TypeScript 界面
server/index.mjs  Express API 与静态页面
server/agent.mjs  有界模型循环、工具白名单、演示模式
server/worker.mjs 后台任务和提醒
server/db.mjs     SQLite 数据层
server/files.mjs  文件访问边界
tests/           自动化集成测试
```

下一步可增补流式输出、检索记忆、资料导入、通知渠道及需要逐次审批的外部连接器。
